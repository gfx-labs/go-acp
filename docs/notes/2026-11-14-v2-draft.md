# v2 draft package

2026-11-14. `v2/` holds the in-development ACP v2 API, generated from the
draft schema release `schema-v2.0.0-alpha.15` in `v2/schema/`. The upstream
draft can change incompatibly in any alpha, and so can this package.

- Same module, package directory `v2` (import `github.com/gfx-labs/go-acp/v2`).
  It is not a Go `/v2` major-version module. If v2 stabilizes as the main
  protocol, a real `go-acp/v2` module replaces this directory.
- The connection, sides, errors, extensions and union helpers are copies of
  the v1 files, as are their tests. They do not depend on the protocol
  version. Changes to them must be made in both places until v2 ships.
- Generator changes needed for v2, neither changing v1 output:
  - The prompt wrapper's best-effort `session/cancel` uses the notification
    type the schema links to the method (`CancelSessionNotification` in v2)
    rather than a fixed `CancelNotification`.
  - ContentBlock's Meta/Annotations clearing only applies to variants that
    have both fields. v2's `ContentBlockOther` has neither.
- Update: download the release assets into `v2/schema/` and run
  `go generate ./...`.
